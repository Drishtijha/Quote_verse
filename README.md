# 🌷 Little Bloom
### A Little Garden of Quotes & Happiness ♡

> *Soft thoughts, happy hearts, and little reminders to keep blooming.* 🌸

Welcome to **Little Bloom**, a cute and dreamy quote generator made to brighten your day. Discover sweet reminders, collect your favourite words, and share a little positivity with people you love.

## 🎀 Lovely Features

- 🌸 **Daily Inspiration** — Find a new quote whenever you need one.
- 💗 **Favourite Quotes** — Save words close to your heart.
- 🧸 **Easy Copy** — Copy quotes with one click.
- 🦋 **Share the Love** — Send beautiful thoughts to friends.
- 🌈 **Colorful Quotes** — Enjoy a playful, vibrant design.
- 🌙 **Dreamy Wallpaper** — A magical purple-and-pink atmosphere.
- 🍓 **Personal Quote Garden** — Keep favourites saved in your browser.
- 📱 **Mobile Friendly** — Made to look lovely on different screens.

## 🫧 Made With Love Using

- HTML5
- CSS3
- JavaScript
- [DummyJSON Quotes API](https://dummyjson.com/quotes)
- Browser Clipboard API
- Web Share API
- Local Storage

## 🩷 Let's Get Started

Keep the project files together like this:

```text
Little-Bloom/
├── index.html
├── style.css
├── script.js
└── wallpaper.png
```

1. Open the folder in Visual Studio Code.
2. Run `index.html` in your browser, preferably with Live Server.
3. Click **Generate Quote** to discover a new thought.
4. Save your favourite quotes and create your own little collection. ✨

## 🍰 How to Use

1. 🌷 Generate a quote.
2. 💕 Copy the words you love.
3. 🦋 Share a little positivity.
4. 💗 Add special quotes to Favourites.
5. 🌸 Remove any quote whenever you like.

## ☁️ A Few Little Notes

- Internet access is needed to load quotes from the API.
- Your favourites are saved in the browser on your current device.
- Sharing and clipboard features depend on browser support and permissions.
- Make sure your wallpaper filename matches the one used in `style.css`.

## 🌼 The Heart Behind Little Bloom

Sometimes, a few kind words can make an ordinary day feel special. Little Bloom is a small project created to spread positivity while learning JavaScript, API fetching, DOM manipulation, responsive CSS, and local storage.
